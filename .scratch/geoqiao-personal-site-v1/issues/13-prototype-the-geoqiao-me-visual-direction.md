# 13 — Prototype the geoqiao.me visual direction

**What to build:** Create a disposable, reviewable UI prototype that uses representative real site content to compare distinct visual directions before production theme work begins.

**Blocked by:** 05 — Deliver the paginated Blog archive; 06 — Deliver Site Profile and Home; 07 — Deliver Blog Tags; 09 — Deliver Ideas end to end; 10 — Deliver Issue-backed About; 11 — Deliver curated Projects.

**Status:** wontfix

- [ ] The prototype answers only the visual-direction question and is clearly separated from production theme code.
- [ ] One command runs the prototype, and multiple meaningfully different directions can be switched without rebuilding.
- [ ] Variants use representative Home, Blog, Idea, About, Projects, and Tags content rather than placeholder marketing copy.
- [ ] Each direction defines an intentional palette, typography roles, layout concept, and one defensible signature element grounded in the personal site’s subject.
- [ ] Desktop and mobile states, keyboard focus, reduced motion, long titles, code, images, comments placement, and empty content are visible for review.
- [ ] A concise comparison records the strengths, risks, and implementation cost of each direction; no variant is merged into production by this ticket.

## Comments

The site owner selected the currently configured Escape2 visual language as the v1 baseline. A prototype no longer gates implementation; broader visual exploration is deferred until the core site is stable.
